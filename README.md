# Blackjack-simulator
Blackjack simulator för GA

# För att köra programmet

Kräver att du har [Python3](https://www.python.org/downloads/) samt [git](https://git-scm.com/install/) installerat. 

Öppna en terminal
windows: 
Klicka `win + r` och skriv in `cmd.exe` och klicka enter. 

mac:
Öppna appen `terminal`.


Klona repot
```
git clone https://github.com/VilgotSmedberg/Blackjack-simulator/
```

Gå in i mappen
```
cd blackjack-simulator
```

Skriv 
```
python3 main.py
```

och njut av simuleringen :)
